# causal-open-data

Openly licensed test and benchmark datasets for causal discovery, shared by [tetrad-rs](https://github.com/kelvinlim/tetrad-rs), [ezcausal](https://github.com/kelvinlim/ezcausal), and [opencausal](https://github.com/kelvinlim/opencausal).

## Contents (planned)

- **Boston College COVID-19 Sleep and Well-Being** (Cunningham, Fields & Kensinger 2021) — CC-BY 4.0, OSF [gpxwa](https://osf.io/gpxwa)
- **MyConnectome** (Poldrack et al. 2015) — CC0 / ODC-PDDL, OpenNeuro [ds000031](https://openneuro.org/datasets/ds000031)

Derivatives and selection rules live here; original downloads are regenerated by scripts. No HCP or other restricted data.
